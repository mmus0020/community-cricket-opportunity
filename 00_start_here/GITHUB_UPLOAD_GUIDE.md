# GitHub Upload Guide

## Recommended repository name
`community-cricket-opportunity`

## Easiest upload method
1. Create a new **Public** repository in GitHub.
2. Name it `community-cricket-opportunity`.
3. Do **not** initialise it with a README, licence or `.gitignore` because this folder already contains them.
4. Extract the ZIP package on your computer.
5. Open the extracted `community-cricket-opportunity` folder.
6. Upload the **contents inside that folder** to the root of the GitHub repository.
7. Commit the upload.
8. Check that the README renders correctly and that the dashboard/report images appear.
9. Copy the repository URL.
10. Add that URL to:
    - your executive brief;
    - resume project entry;
    - LinkedIn Featured section;
    - Cricket Australia application where appropriate.

## Recruiter-facing URL
Your final URL should look like:

`https://github.com/YOUR-USERNAME/community-cricket-opportunity`

## Before sharing publicly
Review the repository once for:
- personal information you do not want public;
- broken relative links;
- file previews;
- correct PDF downloads;
- data attribution.

The folder has been designed so the README is the first page recruiters see.
