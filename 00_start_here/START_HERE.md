If you are reviewing this project for recruitment, research or community-cricket strategy:

1. **2 minutes:** open `../01_executive/Community_Cricket_Opportunity_One_Page_Executive_Brief.pdf`
2. **5 minutes:** read the repository `README.md`
3. **10 minutes:** view `../03_dashboard/Dashboard_Executive_Overview_Preview.png` and the Top-20 model output
4. **Full review:** open `../02_final_report/Community_Cricket_Opportunity_Final_Analytical_Report.pdf`

## Core decision idea
Use **demographic Opportunity Potential** to decide where to investigate, then use cricket-specific **System Readiness** data to diagnose the local constraint before allocating resources.

## Important boundary
This public-data model does not claim to measure true local cricket demand, participation penetration, future registrations or national System Readiness.
