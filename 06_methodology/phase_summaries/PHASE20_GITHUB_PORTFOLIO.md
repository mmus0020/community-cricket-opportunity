# Phase 20 — GitHub Portfolio

The project was reorganised into a recruiter-friendly public repository.

The portfolio places the executive brief, final report and dashboard first, then preserves the full public-data evidence chain:
- raw ABS inputs;
- processed LGA data;
- EDA outputs;
- geographic analysis;
- Model V1 rankings and sensitivity tests;
- strategic segmentation;
- case-study evidence;
- recommendations;
- limitations and validation;
- reproducibility code.

The repository README is designed as the public project landing page. It includes a clear limitation statement so the project is presented as a transparent screening prototype rather than a predictive demand model.
