# Phase 4 — Public Data Audit

## Core public sources
- Cricket Australia Cricket Census / annual reports
- State cricket associations
- ASC AusPlay
- ABS Census
- ABS Regional Population
- ABS age/sex population estimates
- ABS SEIFA
- ABS LGA geography/boundary standards
- Play Cricket / PlayHQ public information

## Key limitation discovered
No clean, nationally available public dataset provides **registered cricket participants by LGA**. Therefore exact local cricket penetration cannot be calculated from public data.

The project was consequently framed as an **opportunity-screening model**, not a participation-demand model.
