# Data

## Raw data
`raw_abs/` contains official Australian Bureau of Statistics workbooks used in the public-data prototype.

These raw files remain unchanged from collection.

## Processed data
`processed/` contains cleaned LGA-level population, youth, SEIFA and master tables.

## Model outputs
`model_outputs/` contains EDA summaries, rankings, sensitivity results, opportunity tiers and geographic summaries.

## Case studies
`case_studies/` contains the five Phase 14 case profiles and evidence matrix.

## Validation
`validation/` contains limitations, claims boundaries, sensitivity summaries, KPI framework and recommendation tables.

## Important
The project does **not** contain Cricket Australia internal participant data. Public demographic data is therefore used as a screening layer rather than a direct measure of cricket demand.

## Data licensing
ABS source data has its own licensing/attribution conditions. See `DATA_ATTRIBUTION.md`. The repository's code license does not override source-data licences.
